# Feature Specification: TED Talks 视频与字幕采集

**Feature Branch**: `009-fetch-ted-talks`

**Created**: 2026-11-08

**Status**: Draft

**Input**: User description: "在 /admin 新建 exercise 弹窗中增加采集 TED Talks 视频与字幕的 tab；管理员提供 TED Talks 链接后，采集视频并存入 COS。弹窗包含现有手动录入 tab 和 Fetch TED Talks tab。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 通过 TED Talks 链接准备练习素材 (Priority: P1)

管理员在新建练习弹窗中切换到“Fetch TED Talks”，粘贴一个 TED Talks 演讲链接并启动采集。完成后，系统已取得该演讲的视频和英文字幕，将视频保存到 COS，并把可供练习使用的视频地址和字幕内容填入当前练习草稿，供管理员确认后创建练习。

**Why this priority**: 这是本功能的核心价值，让管理员无需自行寻找、下载和上传 TED 素材即可准备练习。

**Independent Test**: 使用一个公开且含英文字幕的有效 TED Talks 链接完成采集，确认视频已保存到 COS、草稿中的视频和字幕均可用，并可继续创建练习。

**Acceptance Scenarios**:

1. **Given** 管理员已打开新建练习弹窗，**When** 查看可用录入方式，**Then** 弹窗显示“Manual”和“Fetch TED Talks”两个 tab。
2. **Given** 管理员位于“Fetch TED Talks”tab，**When** 输入公开且含英文字幕的有效 TED Talks 链接并启动采集，**Then** 系统显示采集进度，完成后提供已存入 COS 的视频和对应英文字幕。
3. **Given** 视频与字幕采集成功，**When** 管理员检查练习草稿，**Then** 视频地址和字幕内容已填入，且管理员可继续使用现有创建流程。
4. **Given** 管理员输入的链接无效或素材不可用，**When** 启动采集，**Then** 系统显示明确的失败原因、保留所输入链接以便修正或重试，且不创建练习。

---

### User Story 2 - 保留手动录入方式 (Priority: P2)

管理员仍可在同一弹窗中选择“Manual”，按照现有方式输入视频和字幕并创建练习，不受新增采集功能影响。

**Why this priority**: 手动录入是现有可用路径，也是 TED 链接不适用或采集失败时的必要备选方式。

**Independent Test**: 打开新建练习弹窗，留在或切换到“Manual”tab，按原有步骤输入视频与字幕并成功创建练习。

**Acceptance Scenarios**:

1. **Given** 管理员打开新建练习弹窗，**When** 弹窗首次显示，**Then** 默认选中“Manual”tab，现有字段与操作保持可用。
2. **Given** 管理员在“Fetch TED Talks”tab 有未完成或失败的采集，**When** 切换到“Manual”tab，**Then** 可正常手动录入，且不会被失败的采集结果覆盖。

### Edge Cases

- 输入为空、格式错误、非 TED 域名或并非具体演讲页面的链接时，应在开始采集前提示链接无效。
- TED 页面存在但没有可获取的视频时，应说明视频不可用，不生成不完整的练习素材。
- 演讲没有英文字幕时，应明确提示缺少英文字幕，不以其他语言字幕静默替代。
- 下载、字幕获取或 COS 保存中途失败时，应允许使用同一链接重试，且不将失败结果写入练习草稿。
- 管理员重复点击采集或提交相同链接时，同一弹窗内不得并发启动重复采集任务。
- 采集期间切换 tab 或关闭弹窗时，不得让后续返回结果覆盖另一份练习草稿。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 新建练习弹窗 MUST 提供且仅提供“Manual”和“Fetch TED Talks”两个素材录入 tab。
- **FR-002**: 弹窗 MUST 默认显示“Manual”tab，并保留现有手动输入视频、字幕及创建练习的完整行为。
- **FR-003**: “Fetch TED Talks”tab MUST 提供单个 TED Talks 链接输入框和明确的采集操作入口。
- **FR-004**: 系统 MUST 在采集前验证输入为具体 TED Talks 演讲页面的有效链接，并对空值、无效格式及不支持的页面给出可理解的提示。
- **FR-005**: 对有效链接，系统 MUST 获取同一演讲的可播放视频和对应英文字幕，不得混合不同演讲的素材。
- **FR-006**: 系统 MUST 将采集到的视频保存到现有 COS，并取得可供练习播放的视频地址。
- **FR-007**: 采集成功后，系统 MUST 将视频地址和对应英文字幕填入当前练习草稿，供管理员确认；系统 MUST NOT 未经管理员确认自动创建练习。
- **FR-008**: 系统 MUST 显示待采集、采集中、成功和失败状态，并在采集期间禁止同一弹窗重复启动采集。
- **FR-009**: 采集失败时，系统 MUST 显示可操作的错误信息并保留输入链接，且 MUST NOT 创建练习或用不完整素材覆盖草稿。
- **FR-010**: 管理员 MUST 只有在视频与英文字幕均已成功获取并填入草稿后，才能通过现有创建操作提交该 TED 练习。
- **FR-011**: 采集结果 MUST 仅归属于发起采集的当前练习草稿，切换 tab 或关闭弹窗后不得覆盖其他草稿。
- **FR-012**: TED 采集能力 MUST 仅对现有拥有新建练习权限的管理员开放。

### Key Entities *(include if feature involves data)*

- **TED Talk 来源**: 管理员提供的单个演讲来源，包含原始链接及其有效性和素材可用性状态。
- **采集素材**: 与同一 TED Talk 对应的视频和英文字幕，包含采集状态、COS 视频地址、字幕内容及失败原因。
- **练习草稿**: 管理员正在创建的练习，接收采集成功的视频地址和字幕，并沿用现有创建所需的其他信息。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对公开、可访问且含英文字幕的有效 TED Talks 链接，管理员首次采集成功率达到 95% 以上。
- **SC-002**: 在正常网络条件下，90% 的单个演讲采集可在 5 分钟内完成并进入可确认的练习草稿状态。
- **SC-003**: 100% 的采集成功结果均包含可播放的完整视频和与该演讲对应的英文字幕，不包含只有视频或只有字幕的“成功”结果。
- **SC-004**: 90% 以上的管理员无需借助外部下载或上传工具，即可在首次尝试中完成从粘贴链接到练习素材就绪的流程。
- **SC-005**: 现有手动创建练习路径的全部既有验收场景继续通过，回归通过率为 100%。

## Assumptions

- 本期仅支持公开的单个 TED Talks 演讲页面，不支持播放列表、搜索结果、其他网站或需要登录才能访问的内容。
- 默认采集英文字幕；没有英文字幕时视为素材不完整，不自动选择其他语言。
- 默认选择来源可提供的、适合网页播放的较高质量视频，不提供清晰度选择界面。
- 每次采集仅处理一个链接，不包含批量导入、定时同步或 TED 内容目录浏览。
- 采集完成后仍由管理员确认并通过现有创建流程生成练习，不自动发布练习。
- 沿用现有管理员权限、练习字段校验和 COS 存储配置，不改变其他练习管理功能。
- 管理员仅采集和使用其有权使用的公开内容。
- 本功能面向桌面端管理页面，不增加移动端专属布局。
