# API Contract: Subtitle Configuration

**Feature**: Subtitle Merge & Edit Optimization  
**Endpoint Base**: `/api/subtitles/[exerciseId]/config`  
**Methods**: GET, PUT, DELETE

---

## GET /api/subtitles/[exerciseId]/config

Retrieve the user's subtitle configuration and current progress.

### Request

- Headers:
  - `Authorization: Bearer <token>`

### Response 200

```json
{
  "success": true,
  "config": {
    "configId": "uuid",
    "userId": "uuid",
    "exerciseId": "uuid",
    "mergedGroups": [
      {
        "startIndex": 2,
        "endIndex": 4,
        "label": "Group 1",
        "customText": "Optional edited text for this merged group"
      }
    ],
    "skippedSentences": [5, 6]
  },
  "currentProgress": 0
}
```

### Response 401

```json
{
  "error": "Unauthorized: Authentication required"
}
```

---

## PUT /api/subtitles/[exerciseId]/config

Update the user's subtitle configuration.

### Request

- Headers:
  - `Authorization: Bearer <token>`
  - `Content-Type: application/json`
- Body:

```json
{
  "mergedGroups": [
    {
      "startIndex": 2,
      "endIndex": 4,
      "label": "Group 1",
      "customText": "Optional edited text"
    }
  ],
  "skippedSentences": [5, 6]
}
```

### Validation Rules

- `startIndex` and `endIndex` are 0-based inclusive indices into the original subtitle list.
- `startIndex <= endIndex`.
- Merge groups must not overlap.
- No merge group or skipped sentence may reference an index `< currentProgress`.
- `customText`, when provided, must be a non-empty string after trimming.

### Response 200

```json
{
  "success": true,
  "message": "Subtitle configuration updated. Changes will apply to next playback.",
  "config": { /* updated config */ }
}
```

### Response 400

```json
{
  "error": "Cannot modify merge group starting at sentence 1. Already completed up to sentence 2. Read-only constraint enforced."
}
```

---

## DELETE /api/subtitles/[exerciseId]/config

Reset the user's subtitle configuration to defaults (no merge groups, no skipped sentences).

### Request

- Headers:
  - `Authorization: Bearer <token>`

### Response 200

```json
{
  "success": true,
  "message": "Subtitle configuration reset to defaults",
  "config": { /* default config */ }
}
```

---

## Notes

- The config object returned by GET and PUT uses 0-based indices to match internal data model and client rendering.
- Client UI must display `index + 1` to the user.
- `customText` is optional. When absent, the effective merged text is generated by joining original line texts with single spaces.
