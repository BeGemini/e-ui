# Implementation Plan: Subtitle Merge & Edit Optimization

## Summary

This feature optimizes the existing subtitle customization workflow by fixing the numbering bug, cleaning `\N` formatting artifacts, collapsing merged lines into a single row in the Subtitle Management UI, and allowing users to edit merged subtitle text so it becomes the answer key during dictation practice.

## Technical Context

**Language/Version**: TypeScript 5.x with Next.js 16 (App Router) and React 19

**Primary Dependencies**: Next.js, React, Tailwind CSS 4, shadcn/ui, mysql2

**Storage**: MySQL 8.0 (existing `UserSubtitleConfig` table with JSON columns)

**Testing**: Jest + React Testing Library for unit/integration tests; Playwright for E2E tests

**Target Platform**: Desktop web browsers

**Project Type**: Full-stack Next.js web application

**Performance Goals**: Subtitle list renders without perceptible delay; config save applies on next playback

**Constraints**:
- Must follow e-ui Constitution: shadcn-first UI, strict TypeScript, Next.js API routes only, desktop-only web design.
- No new backend microservices.
- No `any` types without documented justification.

**Scale/Scope**: Single-user subtitle config per exercise; changes are local to user.

## Key Implementation Notes

1. **Numbering Fix**: Normalize `ParsedSubtitle.index` to 0-based logical position across the API; client displays `index + 1`.
2. **`\N` Cleanup**: Centralize text normalization in `lib/subtitle-parser.ts` and apply it in all format parsers.
3. **Effective Subtitle List**: Introduce `applySubtitleConfig(rawSubtitles, config)` to derive the user-facing list. Reuse it in:
   - `/api/practice/[exerciseId]`
   - `/api/practice/[exerciseId]/check`
   - subtitle editor page (`/dashboard/[exerciseId]/subtitles/page.tsx`)
4. **Editable Merged Text**: Extend `MergeGroup` with optional `customText`; update validation schema and the config endpoint.
5. **Practice Answer Key**: Ensure `/api/practice/[exerciseId]/check` computes the effective list and validates `correctText` against it.
6. **Unmerge Behavior**: Removing a merge group discards `customText` and restores original rows.
7. **Read-Only Constraint**: Continue enforcing edits only on rows with `effectiveIndex >= currentProgress`.
