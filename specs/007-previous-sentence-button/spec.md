# Feature Specification: 视频播放器"上一句"按钮

**Feature Branch**: `007-previous-sentence-button`

**Created**: 2026-10-30

**Status**: Draft

**Input**: User description: "现在视频播放器里有一个播放下一句的按钮，我想再加一个播放上一句的按钮"

## 背景

学习者在练习页（听写练习）中通过视频播放器逐句收听视频片段。播放器控制区目前提供：播放/暂停、重播本句、跳到下一句（"Skip & Continue"）、播放速度选择，以及进度条。

现有"跳到下一句"按钮的行为是：立即从下一句开头开始播放；同时把当前句记为"跳过"（准确率 0）并保存进度；清空听写输入框与评分反馈；页面上的"第 X 句 / 共 Y 句"随之更新。当前句是最后一句时该按钮不可用。播放器没有任何全局键盘快捷键。

学习者在听写时经常需要回头再听前一句（例如前一句没听清、想对照上下文），但目前只能拖动进度条，且拖动不会改变"当前句"，播放到当前句结尾的自动暂停也不会生效，体验很差。本功能在播放器中增加与"下一句"对称的"上一句"按钮。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 回到上一句并收听 (Priority: P1)

学习者在练习页的视频播放器控制区点击"上一句"按钮，播放器回到上一句（当前句的前一句），从该句开头开始播放，播放到该句结尾自动暂停；页面的当前句、句序号与进度显示同步切换为上一句，学习者可以重新听写该句。

**Why this priority**: 这是用户明确提出的唯一核心诉求，单独交付即可产生价值。

**Independent Test**: 进入任一练习并前进到第 3 句，点击"上一句"，确认播放器从第 2 句开头开始播放并在第 2 句结尾自动暂停，页面显示"第 2 句"。

**Acceptance Scenarios**:

1. **Given** 学习者当前位于第 N 句（N > 1），**When** 点击"上一句"，**Then** 当前句切换为第 N−1 句，视频从第 N−1 句开头立即开始播放，并在该句结尾自动暂停。
2. **Given** 学习者当前位于第 N 句（N > 1），**When** 点击"上一句"，**Then** 播放器内的"Sentence X / Y"与页面顶部的"Sentence X of Y (百分比)"均更新为第 N−1 句。
3. **Given** 学习者当前位于第 1 句，**When** 查看播放器控制区，**Then** "上一句"按钮显示为不可用状态（与"下一句"在最后一句时的不可用样式一致），点击无任何效果。
4. **Given** 当前句正在播放到一半（或已暂停在句中），**When** 点击"上一句"，**Then** 仍然跳到第 N−1 句开头播放（而不是回到当前句开头；回到当前句开头由已有的"重播本句"负责）。
5. **Given** 学习者已在当前句输入了听写内容或已看到评分反馈，**When** 点击"上一句"，**Then** 听写输入框与评分反馈被清空（与"下一句"切换句子时的行为一致），以便对上一句重新听写。
6. **Given** 学习者已选择非默认播放速度（如 0.5x），**When** 点击"上一句"，**Then** 上一句按所选速度播放。
7. **Given** 学习者回到了第 N−1 句，**When** 对该句完成听写并点击"Next Sentence"、"Skip"或播放器的"下一句"，**Then** 按现有流程保存该句的作答并前进到第 N 句。
8. **Given** 学习者连续点击"上一句"，**When** 每次点击，**Then** 当前句依次后退一句，直到第 1 句后按钮变为不可用。

---

### User Story 2 - 回退不影响已保存的学习进度 (Priority: P1)

学习者回到上一句只是为了再听一遍或重新听写，不应因此把当前句记为"跳过"，也不应丢失已经取得的进度。

**Why this priority**: "下一句"按钮会把当前句记为跳过（准确率 0）并保存进度；若"上一句"照搬这一行为，会错误地产生 0 分记录、拉低整体准确率，直接损害学习数据的正确性。

**Independent Test**: 在第 3 句点击"上一句"后，检查学习记录中没有新增第 3 句的作答记录；刷新页面后，练习仍从回退前已保存的进度位置继续。

**Acceptance Scenarios**:

1. **Given** 学习者位于第 N 句且尚未提交该句，**When** 点击"上一句"，**Then** 不为第 N 句创建任何作答/跳过记录，也不修改其准确率统计。
2. **Given** 学习者回到了第 N−1 句但没有重新提交，**When** 刷新页面或离开后再次进入该练习，**Then** 练习从回退前已保存的进度（第 N 句）继续，而不是第 N−1 句。
3. **Given** 学习者回到了第 N−1 句并重新提交了该句，**When** 提交完成，**Then** 该次作答像其他作答一样被记录，练习前进到第 N 句。

---

### User Story 3 - 键盘与读屏可访问 (Priority: P2)

仅使用键盘的学习者可以聚焦并触发"上一句"按钮，读屏软件能读出按钮名称及其不可用状态。

**Why this priority**: 项目章程要求可访问性（键盘导航、ARIA 标签）；不影响核心功能但为合规必需。

**Independent Test**: 只用 Tab 与 Enter/空格 完成一次"上一句"操作，并用读屏软件确认按钮被读作"上一句"（或等价名称），在第 1 句时被读作不可用。

**Acceptance Scenarios**:

1. **Given** 焦点位于播放器控制区，**When** 用 Tab 移动焦点，**Then** "上一句"按钮可被聚焦并有可见的焦点样式。
2. **Given** "上一句"按钮已聚焦，**When** 按 Enter 或空格，**Then** 效果与鼠标点击一致。
3. **Given** 使用读屏软件或鼠标悬停，**When** 焦点/指针到达该按钮，**Then** 读出/显示其名称（如"Previous sentence"），在不可用时读出不可用状态。

---

### Edge Cases

- 当前位于第 1 句：按钮不可用，不产生任何播放或句子切换。
- 练习只有 1 句：按钮始终不可用（"下一句"同样不可用）。
- 视频尚未加载完成（显示 Loading）时点击"上一句"：句子立即切换，视频加载完成后从上一句开头开始播放，不丢失这次操作。
- 学习者从服务器保存的进度中途恢复（例如从第 5 句继续）：仍可回退到第 4、3、2、1 句。
- 句子列表已应用学习者自己的字幕配置（合并/跳过）：所谓"上一句"指在学习者实际看到的句子序列中的前一句，被跳过的字幕不会被回退到。
- 正在保存作答（"Saving..."）期间点击"上一句"：不得导致句子错乱（例如回退后又被保存流程推进到错误的句子）；保存进行中时按钮应暂时不可用，或保证最终停留在用户最后一次操作所指的句子。
- 回退后拖动进度条：行为与现有一致（进度条只改变播放位置，不改变当前句）。
- 回退后视频源因访问凭证刷新重新加载：保持当前句（上一句）与播放速度不变。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 视频播放器控制区 MUST 提供"上一句"按钮，与"重播本句""下一句"等按钮在视觉风格上保持一致，并使用与"下一句"对称的"向后跳"图标；按钮位于"下一句"的对称位置（控制按钮组中靠左一侧）。
- **FR-002**: 点击"上一句"时，当前句 MUST 切换为学习者实际句子序列中的前一句，并 MUST 从该句开头立即开始播放。
- **FR-003**: 回退后的播放 MUST 遵循现有按句播放规则：播放到该句结尾自动暂停，且使用当前选定的播放速度。
- **FR-004**: 无论当前句是否正在播放、已播放到何处，点击"上一句" MUST 总是跳到前一句开头（不做"先回到本句开头"的判断）。
- **FR-005**: 当前句为第 1 句（或没有可用句子）时，"上一句"按钮 MUST 处于不可用状态，点击不产生任何效果。
- **FR-006**: 切换到上一句时 MUST 清空听写输入框与评分反馈，并 MUST 同步更新播放器与页面顶部的句序号、进度显示。
- **FR-007**: 点击"上一句" MUST NOT 为当前句创建作答或跳过记录，MUST NOT 修改已保存的作答记录、准确率或已保存的练习进度位置。
- **FR-008**: 学习者回退后若未重新提交就刷新或重新进入练习，练习 MUST 从已保存的进度位置继续（即回退前的位置）。
- **FR-009**: 学习者在回退后的句子上提交作答（"Next Sentence"/"Skip"/播放器"下一句"）时，MUST 沿用现有提交与前进流程，前进到下一句。
- **FR-010**: 视频尚未就绪时点击"上一句"，MUST 先切换句子，并在视频就绪后自动从该句开头播放。
- **FR-011**: 作答保存进行中时，"上一句"操作 MUST NOT 导致最终停留的句子与学习者最后一次操作不一致。
- **FR-012**: "上一句"按钮 MUST 支持纯键盘操作（Tab 聚焦、Enter/空格触发），并具备可被读屏软件识别的名称和不可用状态，以及鼠标悬停提示。
- **FR-013**: 现有"下一句""重播本句""播放/暂停"、播放速度及进度条的行为 MUST 保持不变。

### Key Entities

- **当前句（Current Sentence）**: 练习页会话中正在练习的句子，在学习者实际句子序列（已应用合并/跳过配置）中的位置；"上一句"将其减一，最小为第 1 句。
- **已保存进度（Saved Progress）**: 服务器记录的学习者在该练习中的继续位置与作答记录；本功能只读不写，回退操作不会改变它。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 学习者从想回听上一句到上一句开始播放，只需 1 次点击（或 1 次键盘触发），且在 1 秒内开始播放（视频已加载的情况下）。
- **SC-002**: 在第 2 句至最后一句之间任意位置点击"上一句"，100% 情况下切换到正确的前一句、从其开头播放并在其结尾自动暂停。
- **SC-003**: 在第 1 句时，100% 情况下"上一句"不可用且点击无效果。
- **SC-004**: 连续执行 10 次"上一句"/"下一句"混合操作后，新增的作答记录数等于"下一句"/提交操作的次数（"上一句"操作新增 0 条），整体准确率不因回退而变化。
- **SC-005**: 回退后不提交即刷新页面，100% 情况下练习从回退前已保存的位置继续。
- **SC-006**: "上一句"按钮可仅通过键盘完成全部操作，并通过 WCAG 2.1 AA 级别的可访问性检查。

## Assumptions

- "视频播放器"指练习页（`/dashboard/[exerciseId]/practice`）中使用的唯一视频播放器，与 006 倍速功能的范围相同。
- "上一句"是一个导航动作（回听/重新听写），不是"撤销"；因此不对当前句记"跳过"、不回滚已保存进度，这与"下一句"会记录跳过的行为有意不对称。
- 总是跳到前一句开头；"回到本句开头"已由现有的"重播本句"按钮提供，不重复。
- 切换句子时清空输入与反馈，与"下一句"的切换行为保持一致；不为每句保留未提交的草稿。
- 不新增全局键盘快捷键（现有播放器也没有），只要求按钮本身可键盘操作。
- 回退后再次提交某句时，会像现有流程一样追加一条新的作答记录（不覆盖旧记录）；准确率汇总如何处理同一句的多次作答沿用现有规则，不在本期调整。
- 按钮文案/提示沿用播放器现有的英文风格（如 "Previous sentence"），与 "Replay"、"Skip & Continue" 一致。
- 仅面向桌面浏览器（遵循项目章程），不考虑移动端布局。
- 不涉及服务端或数据结构变更。
