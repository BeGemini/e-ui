# Feature Specification: 视频播放器倍速播放

**Feature Branch**: `006-video-playback-speed`

**Created**: 2026-10-30

**Status**: Draft

**Input**: User description: "我要给视频播放器加一个倍速播放的功能，播放速度有 0.25, 0.5, 1, 1.25, 1.5, 然后默认播放速度为1 即可"

## 背景

学习者在练习页（听写练习）中通过视频播放器逐句收听视频片段，播放器目前只提供播放/暂停、重播本句、跳到下一句和进度条，只能以原速播放。对听力较弱的学习者，原速语音过快、难以听清；对熟练的学习者，希望稍快一点以提高效率。本功能在现有播放器中增加播放速度选择。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 选择播放速度收听句子 (Priority: P1)

学习者在练习页的视频播放器控制区看到当前播放速度（默认 1x），可从 0.25x、0.5x、1x、1.25x、1.5x 中选择一个速度；之后播放、重播本句、跳到下一句都按所选速度播放。

**Why this priority**: 这是用户明确提出的唯一核心诉求，单独交付即可产生价值。

**Independent Test**: 进入任一练习，确认默认显示 1x；切换到 0.5x 后播放当前句，该句实际播放用时约为原时长的 2 倍；切换到 1.5x 后用时约为原时长的 2/3。

**Acceptance Scenarios**:

1. **Given** 学习者刚进入练习页，**When** 播放器加载完成，**Then** 播放速度显示为 1x，视频以原速播放。
2. **Given** 播放器已加载，**When** 学习者打开速度选择，**Then** 恰好列出 0.25x、0.5x、1x、1.25x、1.5x 五个选项（按从慢到快排列），并标示当前选中项。
3. **Given** 视频正在播放，**When** 学习者选择 0.5x，**Then** 播放立即以 0.5 倍速继续，不中断、不跳回句首、不改变播放/暂停状态。
4. **Given** 视频处于暂停状态，**When** 学习者选择 1.25x 后点击播放，**Then** 以 1.25 倍速播放。
5. **Given** 已选择非默认速度（例如 0.5x），**When** 学习者点击"重播本句"、"跳到下一句"、或完成本句后进入下一句，**Then** 新的播放仍保持所选速度。
6. **Given** 已选择非默认速度，**When** 某句播放到句尾自动停止，**Then** 停止时机仍正确（不提前、不越过句尾进入下一句内容）。

---

### User Story 2 - 键盘操作选择速度 (Priority: P2)

仅使用键盘的学习者可以聚焦到速度控件、打开选项、选择速度并关闭，且读屏软件能读出当前速度。

**Why this priority**: 项目章程要求可访问性（键盘导航、ARIA 标签）；不影响核心功能但为合规必需。

**Independent Test**: 只用 Tab / 方向键 / Enter / Esc 完成一次速度切换，并用读屏软件确认控件被读作"播放速度"及当前值。

**Acceptance Scenarios**:

1. **Given** 焦点位于播放器控制区，**When** 用 Tab 移动焦点，**Then** 速度控件可被聚焦，且有可见的焦点样式。
2. **Given** 速度控件已聚焦，**When** 用键盘打开、选择并确认某速度，**Then** 速度生效，焦点回到速度控件。
3. **Given** 使用读屏软件，**When** 焦点到达速度控件，**Then** 读出其名称（播放速度）与当前值（如"1x"）。

---

### Edge Cases

- 视频尚未加载完成（显示 Loading）时选择了速度：视频加载完成后应以已选速度播放，而不是被重置为 1x。
- 视频源重新加载（例如访问凭证刷新导致视频地址变化）后：保持学习者已选的速度。
- 学习者离开练习页后再次进入（或刷新页面）：速度恢复为默认 1x。
- 低速（0.25x / 0.5x）播放时：语音音调应保持自然（不明显变低沉），以免影响听写。
- 拖动进度条到其他位置：不改变当前速度。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 视频播放器 MUST 提供播放速度选择控件，选项严格为 0.25x、0.5x、1x、1.25x、1.5x 五档，不提供自定义输入。
- **FR-002**: 每次进入练习页时，播放速度 MUST 默认为 1x。
- **FR-003**: 控件 MUST 始终显示当前播放速度（如"1x"、"0.5x"）。
- **FR-004**: 选择新速度后 MUST 立即对当前播放生效，且不改变播放/暂停状态与当前播放位置。
- **FR-005**: 在同一次练习页会话中，所选速度 MUST 对后续所有播放保持有效，包括：播放/继续、重播本句、跳到下一句、自动进入下一句、拖动进度条、视频源重新加载。
- **FR-006**: 任意速度下，按句播放的结束判定（播放到当前句末尾停止）MUST 与 1x 时行为一致。
- **FR-007**: 降速/加速播放时 MUST 保持语音音调自然（不随速度明显变高或变低）。
- **FR-008**: 速度控件 MUST 支持纯键盘操作，并具备可被读屏软件识别的名称与当前值。
- **FR-009**: 速度控件 MUST 与现有播放器控制按钮在视觉风格上保持一致，并位于播放器控制区内。
- **FR-010**: 离开或刷新练习页后，速度 MUST 恢复为 1x（本期不跨会话记忆用户选择）。

### Key Entities

- **播放速度（Playback Speed）**: 当前练习页会话中的播放倍率，取值限定为 {0.25, 0.5, 1, 1.25, 1.5}，默认值 1；仅存在于页面会话内，不保存到服务器或用户资料。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 学习者从看到播放器到切换至目标速度，操作不超过 2 次点击（或等效键盘操作），且可在 3 秒内完成。
- **SC-002**: 选择某速度后播放一句时长为 T 的句子，实际播放用时与 T ÷ 倍速 的偏差不超过 10%（五档全部满足）。
- **SC-003**: 在非 1x 速度下连续完成 10 句（包含重播、跳句、进入下一句），速度在 100% 的播放中保持不变，且每句均在句尾正确停止。
- **SC-004**: 首次进入练习页时，100% 情况下初始速度为 1x。
- **SC-005**: 速度控件可仅通过键盘完成全部操作，并通过 WCAG 2.1 AA 级别的可访问性检查。

## Assumptions

- "视频播放器"指练习页（`/dashboard/[exerciseId]/practice`）中使用的唯一视频播放器；用户附带的后台管理页面（`/admin`）当前不包含视频播放器，不在本期范围。
- 速度仅在当前页面会话内保持，不跨页面刷新、不跨设备、不写入用户偏好设置（默认 1x 满足"默认播放速度为 1 即可"）。
- 不新增全局键盘快捷键（如 `<` / `>` 调速），只要求速度控件本身可键盘操作。
- 速度选项的显示格式统一为"数值 + x"（如 0.25x、1x）。
- 仅面向桌面浏览器（遵循项目章程），不考虑移动端布局。
- 不涉及任何服务端或数据变更。
