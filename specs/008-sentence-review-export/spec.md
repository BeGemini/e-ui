# Feature Specification: 练习句子记录、回顾页与导出

**Feature Branch**: `008-sentence-review-export`

**Created**: 2026-10-31

**Status**: Draft

**Input**: User description: "我要加个功能，就是我在点击检查的时候，记录下这次我写的内容，如果点多次检查，那就覆盖。然后呢，加一个页面，可以显示我在这个练习里的每个句子，再加个 switch 开关，用来显示和隐藏原文，显示原文的话，原文要显示在我的句子的下面，原文用浅浅的绿色作为背景色，然后加个导出的按钮，可以导出为 docx 和 pdf"

**Update**: "既然点击下一句也会存的话，那就存成一份，覆盖掉，因为有的时候我可能也不去点检查，所以只是给检查加一个保存的接口，只是点下一句的时候要支持覆盖，不要报错就行"

## 背景

学习者在练习页（听写练习）中逐句收听视频片段，在听写输入框中写下听到的句子，然后点击"Check"（检查）按钮（或按 Ctrl+Enter）查看准确率与逐词评分反馈。之后可点击"Next Sentence"（保存本句作答并前进）或"Skip"（记为跳过）。

目前点击"Check"只会返回评分反馈，**不会保存**学习者写的内容；只有点击"Next Sentence"/"Skip"时才会生成作答记录，而且每次都会**新增**一条，同一句可能出现多条作答记录。学习者没有地方集中回看自己在某个练习里写过的全部句子，也无法把它们导出成文档留存或打印。

本功能：

1. 每句只保留**一份**作答记录（沿用现有作答记录，不另建一套）。点击"Check"时保存/覆盖该句的作答记录；点击"Next Sentence"/"Skip"时同样保存/覆盖该句的作答记录（若已存在则覆盖，不报错、不新增）。以最后一次保存为准。学习者即使不点"Check"、直接点"Next Sentence"，该句内容也会被记录。
2. 新增一个"我的句子"页面，按句子顺序列出学习者在该练习里记录的所有句子。
3. 页面上提供一个开关，用于显示/隐藏原文；显示时，每句原文位于学习者句子的正下方，并以浅绿色背景区分。
4. 页面上提供导出按钮，可导出为 Word（.docx）和 PDF 文档。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 每句只存一份作答，"Check"与"Next Sentence"都会保存并覆盖 (Priority: P1)

学习者在练习页对某一句写下听写内容并点击"Check"，系统在显示评分反馈的同时，把这次写的内容（连同准确率、逐词反馈、原文）保存为该句的作答记录。之后点击"Next Sentence"或"Skip"时，同样保存到这一份记录上（覆盖），然后前进到下一句。任何情况下同一学习者、同一练习、同一句都只有一条作答记录，以最后一次保存为准；如果学习者没点"Check"直接点了"Next Sentence"/"Skip"，也照常保存。

**Why this priority**: 这是回顾页和导出的数据来源；没有记录，后续功能都无从谈起。单独交付后，记录即已被保存，学习者下次进入回顾页即可看到。

**Independent Test**: 在某练习第 2 句输入 "hello world" 点击"Check"，再改为 "hello word" 点击"Check"，然后点"Next Sentence"；用"上一句"回到第 2 句改为 "hello words" 再点"Next Sentence"。查看该练习的作答记录：第 2 句只有一条，内容为 "hello words"，整个过程没有报错。

**Acceptance Scenarios**:

1. **Given** 学习者在第 N 句输入了非空内容，**When** 点击"Check"（或按 Ctrl+Enter）且评分成功返回，**Then** 系统保存该句的作答记录（学习者内容原样保存，含大小写与标点；并保存准确率、逐词反馈、原文与保存时间），但**不前进**到下一句、不改变当前句位置。
2. **Given** 第 N 句已有作答记录，**When** 学习者修改内容后再次点击"Check"，**Then** 该句记录被覆盖为新内容，不产生第二条记录。
3. **Given** 第 N 句已有作答记录（无论来自"Check"还是之前的"Next Sentence"/"Skip"），**When** 学习者点击"Next Sentence"或"Skip"，**Then** 该句记录被覆盖为当前内容，然后正常前进到下一句；**不报错、不新增记录**。
4. **Given** 学习者没有点"Check"，**When** 直接点击"Next Sentence"或"Skip"，**Then** 该句同样被保存为一条作答记录（与现有行为一致）。
5. **Given** 学习者通过"上一句"回到之前的句子并重新"Check"或"Next Sentence"，**When** 保存完成，**Then** 该句的记录被覆盖为最新内容。
6. **Given** 评分请求失败（例如网络错误），**When** 学习者看到错误提示，**Then** 该次内容不会被保存，原有记录保持不变。
7. **Given** 学习者完成整个练习，**When** 系统计算总体准确率，**Then** 每句只按其唯一一条（最新）作答记录参与计算，跳过的句子仍按现有规则排除。

### User Story 2 - 在"我的句子"页面回看全部句子并切换原文 (Priority: P1)

学习者从练习相关页面进入某练习的"我的句子"页面，按句子顺序看到自己在该练习里记录的每一句。页面上有一个"显示原文"开关：关闭时只显示自己的句子；打开时，每句原文显示在对应的"我的句子"正下方，原文区域使用浅浅的绿色背景。

**Why this priority**: 这是用户明确要求的核心页面，是"回顾"价值的直接体现。

**Independent Test**: 对某练习的第 1、3、5 句分别保存过作答（点"Check"或"Next Sentence"均可），进入该练习的"我的句子"页面，确认按 1、3、5 的顺序列出三条记录；打开开关后每条下方出现浅绿色背景的原文；关闭开关后原文全部隐藏。

**Acceptance Scenarios**:

1. **Given** 学习者在某练习中有若干句记录，**When** 打开该练习的"我的句子"页面，**Then** 页面显示练习标题，并按句子在练习中的顺序列出每条记录，每条带有句序号（如"第 3 句"）与学习者写的内容。
2. **Given** 页面刚打开，**When** 查看"显示原文"开关，**Then** 开关默认为关闭状态，页面只显示学习者的句子。
3. **Given** 开关关闭，**When** 学习者打开开关，**Then** 每条记录下方立即显示该句原文，原文区域有浅绿色背景，与学习者的句子在视觉上明显区分；无需重新加载页面。
4. **Given** 开关打开，**When** 学习者关闭开关，**Then** 所有原文立即隐藏。
5. **Given** 学习者在该练习中没有任何记录，**When** 打开"我的句子"页面，**Then** 页面显示空状态提示（例如"还没有记录，去练习中作答后这里会显示你的句子"），并提供返回练习的入口；导出按钮不可用。
6. **Given** 学习者位于练习详情页或练习页，**When** 查找入口，**Then** 能看到进入该练习"我的句子"页面的按钮/链接。
7. **Given** 学习者 A 与学习者 B 都练习了同一练习，**When** A 打开"我的句子"页面，**Then** 只看到 A 自己的记录。

### User Story 3 - 导出为 Word（.docx）或 PDF (Priority: P2)

学习者在"我的句子"页面点击"Export"（导出）按钮，选择 Word（.docx）或 PDF，浏览器下载一份包含这些句子的文档，便于留存、打印或分享给老师。

**Why this priority**: 用户明确要求，但依赖于记录和回顾页先存在；即使没有导出，回顾页本身也已可用。

**Independent Test**: 在有 10 条记录的练习的"我的句子"页面，分别在开关关闭和打开时导出 .docx 与 .pdf，用常见办公/阅读软件打开，确认内容、顺序与页面一致，原文（如包含）带浅绿色背景。

**Acceptance Scenarios**:

1. **Given** 页面有记录，**When** 学习者点击导出按钮，**Then** 出现两个选项：Word（.docx）与 PDF。
2. **Given** 学习者选择 Word（.docx），**When** 导出完成，**Then** 浏览器下载一个可被常见文字处理软件正常打开的 .docx 文件。
3. **Given** 学习者选择 PDF，**When** 导出完成，**Then** 浏览器下载一个可被常见 PDF 阅读器正常打开的 .pdf 文件。
4. **Given** 导出文档，**When** 打开查看，**Then** 文档包含练习标题、导出日期，以及按句子顺序排列的每一句（句序号 + 学习者写的内容）。
5. **Given** "显示原文"开关为打开状态，**When** 导出，**Then** 文档中每句原文位于学习者句子正下方，并带有与页面一致的浅绿色背景；**Given** 开关为关闭状态，**When** 导出，**Then** 文档中不包含原文（即"所见即所导"）。
6. **Given** 导出过程中，**When** 文件尚未生成完成，**Then** 导出按钮显示进行中状态并防止重复点击；若导出失败，显示友好的错误提示，页面状态不变。
7. **Given** 句子中包含撇号、引号、连字符等标点或非英文字符，**When** 导出，**Then** 这些字符在两种格式中都能正确显示，不出现乱码或缺字。

---

### User Story 4 - 键盘与读屏可访问 (Priority: P3)

仅使用键盘的学习者可以聚焦并操作"显示原文"开关与导出按钮及其选项；读屏软件能读出开关名称与当前开/关状态，以及导出选项名称。

**Why this priority**: 项目要求可访问性，但不影响核心功能的交付。

**Independent Test**: 仅用 Tab/Shift+Tab、空格/回车操作开关与导出；用读屏软件确认开关被读作"显示原文，开/关"。

**Acceptance Scenarios**:

1. **Given** 学习者使用键盘，**When** Tab 到开关并按空格，**Then** 开关切换状态，焦点可见。
2. **Given** 学习者使用键盘，**When** Tab 到导出按钮并按回车，**Then** 可用方向键/Tab 选择 Word 或 PDF 并触发下载。
3. **Given** 读屏软件开启，**When** 焦点在开关上，**Then** 读出名称与当前状态。

---

### Edge Cases

- **同一句反复检查/反复前进**：只保留最后一次保存（"Check"、"Next Sentence"或"Skip"任一）的内容与时间。
- **Check 后又修改，直接点 Next Sentence**：以点"Next Sentence"时的内容覆盖（与现有"Next Sentence"保存当前输入的行为一致）。
- **Skip 时输入为空**：照常保存一条空内容的作答记录（与现有行为一致）；回顾页中该句显示为"已跳过"占位，导出同样显示占位。
- **输入为空或仅空白时点 Check**：与现有行为一致，不能提交"Check"，因此不产生/不覆盖记录。
- **历史重复数据**：功能上线前同一句可能已有多条作答记录，上线时每句只保留最新的一条，其余清理掉，之后不再产生重复。
- **学习者事后修改了字幕设置（合并/跳过句子）导致句子划分变化**：每条记录保存保存当时的原文快照，回顾页与导出显示该快照原文，保证"我的句子"与原文始终对应；记录按句序号排序。
- **管理员修改或删除了练习**：练习被删除后其"我的句子"页面不可访问（显示"练习不存在"）；练习字幕被修改时，已有记录仍显示保存时的原文快照。
- **重新开始/重做练习**：已有记录不清空；重做时再次保存按覆盖规则更新对应句。
- **很长的练习（数百句）**：页面可完整滚动浏览，导出文档包含全部记录并自动分页。
- **很长的句子**：在页面与导出文档中自动换行，不被截断。
- **未登录或登录失效**：访问"我的句子"页面时按现有方式引导登录；导出不可用。
- **记录保存失败但评分成功**：评分反馈照常显示，不打断练习；记录未保存不应阻塞学习者继续练习（可给出轻量提示）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 提供一个"保存本句作答"的能力供"Check"使用：学习者对某句点击"Check"（含 Ctrl+Enter）且评分成功后，保存该句的作答记录（学习者内容原样保存、准确率、逐词反馈、原文快照、保存时间），且 MUST NOT 前进当前句位置或改变完成状态。
- **FR-002**: 系统 MUST 保证同一学习者在同一练习的同一句最多只有一条作答记录；"Check"、"Next Sentence"、"Skip"任何一次保存都以"有则覆盖、无则新增"的方式写入，并更新保存时间。
- **FR-003**: "Next Sentence"/"Skip"在该句已有记录时 MUST 覆盖该记录并正常前进，MUST NOT 报错或新增重复记录；其余现有行为（前进到下一句、最后一句时标记完成）保持不变。
- **FR-004**: 评分失败时 MUST NOT 创建或覆盖记录。
- **FR-004a**: 完成练习时的总体准确率 MUST 基于每句唯一的作答记录计算，跳过句子的排除规则保持不变。
- **FR-004b**: 上线时 MUST 将已有的同句多条作答记录合并为每句仅保留最新一条。
- **FR-005**: 记录 MUST 跟随学习者账号持久保存，换设备或刷新后仍可查看。
- **FR-006**: 系统 MUST 提供每个练习独立的"我的句子"页面，按句序号升序显示该学习者在该练习中的全部记录，每条包含句序号与学习者写的内容，并在页面顶部显示练习标题。
- **FR-007**: 学习者 MUST 只能查看和导出自己的记录。
- **FR-008**: 页面 MUST 提供"显示原文"开关，默认关闭；打开时在每条学习者句子正下方显示该句原文，关闭时隐藏；切换即时生效，无需重新加载。
- **FR-009**: 原文区域 MUST 使用浅绿色背景，与学习者句子明显区分，且文字与背景的对比度满足可读性（无障碍对比度）要求。
- **FR-010**: 练习详情页与练习页 MUST 提供进入该练习"我的句子"页面的入口；页面 MUST 提供返回练习的入口。
- **FR-011**: 没有记录时，页面 MUST 显示空状态提示，且导出不可用。
- **FR-012**: 页面 MUST 提供导出按钮，提供 Word（.docx）与 PDF 两种格式，选择后直接下载文件。
- **FR-013**: 导出文档 MUST 包含练习标题、导出日期，以及与页面一致顺序的全部记录（句序号 + 学习者内容）；当"显示原文"开关打开时，MUST 在每句下方包含原文并使用浅绿色背景，关闭时 MUST NOT 包含原文。
- **FR-014**: 导出文件名 MUST 可辨识，包含练习标题与导出日期（例如 `<练习标题>-我的句子-2026-10-31.docx`），并去除文件名中的非法字符。
- **FR-015**: 导出进行中 MUST 显示进行中状态并防止重复触发；失败时 MUST 显示友好错误提示。
- **FR-016**: 导出文档 MUST 正确显示句中出现的各种标点与非英文字符，长内容自动换行与分页。
- **FR-017**: 开关与导出控件 MUST 可通过键盘操作，并具备读屏可读的名称与状态。

### Key Entities

- **作答记录（我的句子）**：沿用现有作答记录，不新建实体。表示某学习者在某练习中对某一句最近一次保存（"Check"/"Next Sentence"/"Skip"）时的作答。关键属性：所属学习者的练习进度、句序号、学习者内容、原文快照、准确率、逐词反馈、最近保存时间。新增唯一性约束：同一练习进度 + 句序号仅一条。
- **练习**：已有实体，提供标题与句子列表；一个练习对应多个学习者的多条句子记录。
- **导出文档**：由回顾页当前内容生成的一次性下载文件（.docx 或 .pdf），不在系统中保存。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% 成功的"Check"/"Next Sentence"/"Skip"操作都会产生或更新对应句的记录；对同一句混合进行 5 次"Check"与"Next Sentence"后，该句记录数始终为 1、内容为最后一次保存的输入，且全程无报错。
- **SC-002**: 记录功能上线后，"Check"从点击到看到评分反馈的等待时间与上线前相比无明显增加（学习者感知不到差异）。
- **SC-003**: 学习者从练习详情页出发，可在 2 次点击内打开"我的句子"页面；包含 200 句记录的页面在 2 秒内完整显示。
- **SC-004**: 切换"显示原文"开关后，原文的显示/隐藏在学习者感知上是即时的（无加载等待）。
- **SC-005**: 对包含 200 句记录的练习，.docx 与 .pdf 导出均在 10 秒内完成下载，且 100% 的导出文件能被常见办公软件/PDF 阅读器正常打开，内容与页面一致。
- **SC-006**: 在验收测试中，学习者首次使用即可在无说明的情况下完成"打开回顾页 → 打开原文 → 导出 PDF"的流程（成功率 ≥ 90%）。

## Assumptions

- "我的句子"页面列出**有作答记录**的句子（点过"Check"、"Next Sentence"或"Skip"的句子）；从未作答的句子不显示。内容为空的跳过记录显示为"已跳过"占位。
- "Check"保存的作答记录会带准确率，因此即使学习者没点"Next Sentence"，该句也会参与完成时的总体准确率计算；这符合"每句一份、以最新为准"的预期。
- 记录以账号为单位保存在服务端（与现有学习进度一致），而非仅保存在当前浏览器。
- 记录在保存当时存下原文快照（现有作答记录已保存原文），以应对学习者之后修改字幕合并/跳过设置或管理员修改字幕的情况。
- "浅浅的绿色"指非常浅的绿色底色（接近白色的淡绿），原文文字保持深色以确保可读；页面与导出文档使用相同观感的颜色。
- "显示原文"开关状态只在当前页面会话中有效，默认关闭，不需要跨会话记忆。
- 导出内容遵循"所见即所导"：是否包含原文由导出时开关的状态决定。导出不包含准确率、逐词评分等额外信息。
